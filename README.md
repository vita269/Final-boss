# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Веб-приложение для управления задачами с аутентификацией и Docker поддержкой.

 Функциональность
- ✅ Добавление, редактирование, удаление задач
- ✅ Повторяющиеся задачи
- ✅ Поиск задач
- ✅ JWT аутентификация
- ✅ Docker контейнеризация

Запуск

Локально
\`\`\`bash
export TODO_PASSWORD=12345
go run main.go
\`\`\`

Docker
\`\`\`bash
docker build -t final-boss .
docker run -d -p 7540:7540 -e TODO_PASSWORD=12345 final-boss
\`\`\`

 API
- \`POST /api/signin\` - аутентификация
- \`GET /api/tasks\` - список задач
- \`POST /api/task\` - создать задачу
- \`PUT /api/task\` - обновить задачу
- \`DELETE /api/task\` - удалить задачу

* задания со звездочками выполнены
